✨ Sparkle Showdown ✨

Grab the sparkles before the other players do!

Create a room and send the same room code to the other player.

Players

How to play

  1. Open the game on each device.
  2. One player creates a room.
  3. Everyone enters the same room code.
  4. Use arrow keys, WASD, or the mobile buttons.
  5. Touch a ⭐ to score a point.
  6. Highest score wins!
